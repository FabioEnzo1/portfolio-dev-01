## Sobre o projeto

O Task Manager é uma aplicação desktop desenvolvida em Java para ajudar na organização das atividades do dia a dia. A interface gráfica feita com JavaFX permite gerenciar tarefas de forma simples e eficiente.

## Funcionalidades

- Criação de tarefas.
- Listagem e organização das atividades.
- Interface gráfica amigável.
- Testes automatizados com JUnit.

## Estrutura e tecnologias

O projeto utiliza Maven para gerenciamento de dependências e organização do build. Foi desenvolvido com Java e JavaFX, com testes automatizados escritos usando JUnit.

## Como executar

É necessário ter Java 17 ou superior e Maven instalados. Na pasta do projeto, execute:

```bash
mvn clean install
mvn javafx:run
```
